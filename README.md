# 🌐 Muskan | Developer Portfolio | https://muskan-portfolio-2025.vercel.app/

A modern, responsive developer portfolio built with **React + Vite**, showcasing my skills, projects, and resume.

🔗 **Live Demo:** https://muskan-portfolio-2025.vercel.app/
📄 **Resume:** Available in the Resume section of the website

---

## ✨ Features

- ⚡ Built with **React + Vite**
- 🎨 Clean dark-themed UI
- 🧭 Smooth navigation using **React Router**
- 🌌 Animated particle background
- 🧑‍💻 About section with skills & tools
- 📂 Projects section with cards
- 📄 Resume preview & download (PDF)
- 📱 Fully responsive design

---

## 🛠️ Tech Stack

**Frontend**
- React.js
- Vite
- React Router DOM
- React Bootstrap
- Bootstrap 5
- React Icons

**Other Libraries**
- react-pdf
- tsparticles (for particle background)
